## 📖 درباره پروژه

**Learnify** یک وب‌سایت آموزشی مدرن است که با هدف معرفی خدمات تدریس خصوصی و آموزش آنلاین طراحی و توسعه داده شده است.

این وب‌سایت به دانش‌آموزان کمک می‌کند تا دوره‌های آموزشی مختلف را مشاهده کنند، با مدرس آشنا شوند، روش تدریس را بررسی کنند، پکیج‌های آموزشی را بشناسند و درخواست رزرو کلاس ثبت کنند.

تمرکز اصلی این پروژه بر طراحی رابط کاربری حرفه‌ای، توسعه واکنش‌گرا، استفاده از قابلیت‌های پیشرفته CSS و ایجاد تجربه کاربری ساده و جذاب است.

## 🛠️ تکنولوژی‌ها و ابزارهای استفاده‌شده

- **HTML5:** ساختاردهی معنایی و استاندارد صفحات وب.
- **CSS3:** طراحی رابط کاربری و استایل‌دهی.
- **Flexbox:** ایجاد چیدمان‌های انعطاف‌پذیر.
- **CSS Grid:** طراحی ساختارهای چندستونه و پیشرفته.
- **Media Queries:** ایجاد طراحی واکنش‌گرا.
- **Container Queries:** واکنش‌گرایی مبتنی بر اندازه کامپوننت‌ها.
- **CSS Custom Properties:** مدیریت متغیرها و توکن‌های طراحی.
- **CSS clamp():** ایجاد تایپوگرافی منعطف.
- **Vazirmatn:** استفاده از فونت فارسی.

> این پروژه با HTML5 و CSS3 خالص توسعه داده شده و از JavaScript، Bootstrap و Tailwind CSS استفاده نمی‌کند.

## 📱 طراحی واکنش‌گرا (Responsive Design)

در توسعه این پروژه از رویکرد Mobile First استفاده شده است تا وب‌سایت در اندازه‌های مختلف نمایشگر، تجربه کاربری مناسبی ارائه دهد.

تکنیک‌های استفاده‌شده:

- طراحی مبتنی بر عرض‌های منعطف.
- استفاده از CSS Grid با `auto-fit` و `minmax()`.
- استفاده از Flexbox برای مدیریت چیدمان.
- تعریف نقاط شکست مختلف با Media Queries.
- استفاده از Container Queries برای کامپوننت‌های مستقل.
- تایپوگرافی و تصاویر واکنش‌گرا.
- مدیریت محتوای طولانی و جلوگیری از اسکرول افقی.
